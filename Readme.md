# Customer Spending & Engagement Analytics

End-to-end data analytics and machine learning project analyzing customer spending behavior and engagement patterns using credit card transaction data.

## Project Objectives

- Analyze customer spending patterns
- Identify churn risk customers
- Perform customer segmentation
- Build predictive ML models for churn prediction

## Dataset

Bank Customer Churn Dataset

## Project Structure

dataset/
Raw dataset and preprocessing scripts

documentation/
Data dictionary and dataset description

notebook/
Jupyter notebooks for analysis

sql_queries/
SQL analysis queries

## Key Techniques

- Data Governance
- Exploratory Data Analysis
- Feature Engineering
- Customer Segmentation
- Machine Learning Modeling
